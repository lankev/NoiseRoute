# Sources techniques primaires

Consultées lors de la préparation du projet ; les API et les pilotes évoluent. La provenance logicielle exacte de chaque run se trouve dans son manifeste.

- Qiskit, plugins de transpilation : https://quantum.cloud.ibm.com/docs/en/api/qiskit/transpiler_plugins
- PassManagerStagePlugin : https://quantum.cloud.ibm.com/docs/en/api/qiskit/qiskit.transpiler.preset_passmanagers.plugin.PassManagerStagePlugin
- IBM AI transpiler, code et installation : https://github.com/Qiskit/qiskit-ibm-transpiler
- MQT Bench, API et usage : https://mqt.readthedocs.io/projects/bench/en/latest/usage.html
- MQT Bench, publication : https://arxiv.org/abs/2204.13719
- QASMBench, code, corpus, licence : https://github.com/pnnl/QASMBench
- SABRE, Li, Ding et Xie : https://arxiv.org/abs/1809.02573
- GATv2, Brody, Alon et Yahav : https://arxiv.org/abs/2105.14491
- PPO, Schulman et al. : https://arxiv.org/abs/1707.06347
- OpenVINO, périphérique NPU : https://docs.openvino.ai/2026/openvino-workflow/running-inference/inference-devices-and-modes/npu-device.html
- PyTorch, installation : https://pytorch.org/get-started/locally/
- Intel Core Ultra 9 185H, caractéristiques : https://www.intel.com/content/www/us/en/products/sku/236849/intel-core-ultra-9-processor-185h-24m-cache-up-to-5-10-ghz/specifications.html

Les idées SABRE, PPO, GATv2 et les corpus restent attribuées à leurs auteurs. NoiseRoute est une implémentation expérimentale, sans affiliation IBM/Intel/MQT revendiquée.
